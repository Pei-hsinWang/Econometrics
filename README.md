# 拒绝H0的日常 —— 双重差分法分析项目

本项目记录了使用**双重差分法**（Difference-in-Differences, DiD）进行实证分析的过程与结果。主要用于研究某项政策或干预对特定群体的影响。

## 📄 文件说明

### `双重差分法/双重差分1.do`

- **功能**: 使用 STATA 编写的双重差分法分析代码。
- **内容**:
  - 数据导入
  - 变量设置
  - 描述性统计
  - DID模型
  - 平行趋势分析

### `双重差分法/案例数据.xlsx`

- **格式**: Excel (.xlsx)
- **内容**:
  - 包含个体标识符 (id)
  - 时间变量 (年份)
  - 政策实施时间 (干预时间)
  - 是否为处理组 (Treat)
  - 结果变量 (Y)
